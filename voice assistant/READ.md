# 1.🎙️ Voice Assistant (Jarvis Style)


Meet your personal Python Voice Assistant 🤖 — just like Jarvis!
This program listens voice commands, speaks back, and performs real-time actions like opening websites, searching Wikipedia, or telling the current time ⏰.

⚙️ Functionalities

🗣️ Speech Recognition — understands your spoken commands

💬 Text-to-Speech (TTS) — responds to you in a natural voice

📚 Wikipedia Search — summarizes any topic you ask for

🌐 Opens Websites — YouTube, Google, Stack Overflow, Spotify, etc.

⏰ Tells the Current Time — just say “what’s the time”

👋 Greets You — based on time (Morning, Afternoon, or Evening)

   opens chatgpt (for any research)
    
❌ Exit Command — say “quit” to close the assistant

🧠 Technologies Used

🔹 pyttsx3 → Text-to-speech engine

🔹 speech_recognition → For capturing and processing voice

🔹 datetime → To track and announce current time

🔹 wikipedia → For fetching quick information

🔹 webbrowser → For automating web actions

💻 Example Commands

🗨️ “Open YouTube”

🗨️ “Search Artificial Intelligence on Wikipedia”

🗨️ “What’s the time?”

🗨️ “Quit”
